# Data-Science-lab-exp01
# Iris Dataset Analysis

## Objective

Perform basic data analysis on the Iris dataset using Python and Pandas.

## Work Done

* Loaded `iris.csv` using Pandas.
* Displayed the last 10 records using `head()`.
* Checked dataset information using `info()`.
* Generated summary statistics using `describe()`.
* Checked missing values using `isnull().sum()`.

## Result

The dataset contains **150 rows and 5 columns** with **no missing values**.

* Python
* Pandas
